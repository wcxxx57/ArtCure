# ArtCure AI 服务器部署指南

## 📋 概述

本指南将帮助你：
1. 在现有阿里云服务器上部署 AI 服务器
2. 配置生产环境
3. 后期平滑迁移到新服务器

## 🖥️ 服务器要求

### 最低配置
- **CPU**: 2核
- **内存**: 4GB
- **硬盘**: 20GB 可用空间
- **系统**: Ubuntu 18.04+ / CentOS 7+
- **网络**: 可访问外网（下载模型和调用 API）

### 推荐配置
- **CPU**: 4核
- **内存**: 8GB
- **硬盘**: 40GB 可用空间

## 🚀 部署步骤

### 步骤 1: 连接服务器

```bash
# 使用 SSH 连接你的阿里云服务器
ssh root@your-server-ip
# 或者使用阿里云控制台的网页终端
```

### 步骤 2: 安装基础环境

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装 Python 3.9+ 和必要工具
sudo apt install -y python3.9 python3.9-venv python3.9-dev python3-pip
sudo apt install -y git curl wget nginx supervisor

# 验证 Python 版本
python3.9 --version
```

### 步骤 3: 创建项目目录和用户

```bash
# 创建专用用户（可选，但推荐）
sudo adduser artcure
sudo usermod -aG sudo artcure

# 切换到新用户
sudo su - artcure

# 创建项目目录
mkdir -p /home/artcure/projects
cd /home/artcure/projects
```

### 步骤 4: 上传项目代码

**方法一：Git 克隆（推荐）**
```bash
# 如果你的代码已推送到 GitHub
git clone https://github.com/your-username/ArtCure.git
cd ArtCure/ai-server
```

**方法二：直接上传**
```bash
# 在本地打包（排除 venv）
# Windows PowerShell:
cd E:\ArtCure\ai-server
Compress-Archive -Path *.py,*.txt,*.md,knowledge_base,*.example -DestinationPath ai-server.zip

# 然后使用 scp 或阿里云控制台上传
scp ai-server.zip artcure@your-server-ip:/home/artcure/projects/
```

### 步骤 5: 配置 Python 环境

```bash
cd /home/artcure/projects/ArtCure/ai-server

# 创建虚拟环境
python3.9 -m venv venv

# 激活虚拟环境
source venv/bin/activate

# 升级 pip
pip install --upgrade pip

# 安装依赖
pip install -r requirements.txt
```

### 步骤 6: 配置环境变量

```bash
# 复制环境变量模板
cp .env.example .env

# 编辑环境变量
nano .env
```

在 `.env` 文件中填入：
```bash
DEEPSEEK_API_KEY=sk-your-deepseek-api-key-here
DEEPSEEK_API_BASE=https://api.deepseek.com
EMBEDDING_MODEL=BAAI/bge-small-zh-v1.5
LLM_MODEL=deepseek-chat
LLM_MAX_TOKENS=1024
LLM_TEMPERATURE=0.7
```

### 步骤 7: 构建向量数据库

```bash
# 首次运行，构建向量索引
python build_index.py
```

### 步骤 8: 测试运行

```bash
# 测试启动服务器
python main.py
```

另开一个终端测试：
```bash
curl http://localhost:8000/health
```

如果看到健康检查成功，说明基础配置正确。按 `Ctrl+C` 停止测试。

### 步骤 9: 配置进程管理器

使用 Supervisor 来管理 AI 服务器进程：

```bash
# 创建 Supervisor 配置文件
sudo nano /etc/supervisor/conf.d/artcure-ai.conf
```

填入以下内容：
```ini
[program:artcure-ai]
directory=/home/artcure/projects/ArtCure/ai-server
command=/home/artcure/projects/ArtCure/ai-server/venv/bin/python main.py
user=artcure
autostart=true
autorestart=true
redirect_stderr=true
stdout_logfile=/var/log/artcure-ai.log
environment=PATH="/home/artcure/projects/ArtCure/ai-server/venv/bin"
```

启动服务：
```bash
# 重新加载 Supervisor 配置
sudo supervisorctl reread
sudo supervisorctl update

# 启动服务
sudo supervisorctl start artcure-ai

# 检查状态
sudo supervisorctl status artcure-ai

# 查看日志
sudo tail -f /var/log/artcure-ai.log
```

### 步骤 10: 配置 Nginx 反向代理

```bash
# 创建 Nginx 配置
sudo nano /etc/nginx/sites-available/artcure-ai
```

填入以下内容：
```nginx
server {
    listen 80;
    server_name your-domain.com;  # 替换为你的域名或IP

    # AI 服务器代理
    location /ai/ {
        proxy_pass http://127.0.0.1:8000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 60s;
        
        # 处理跨域
        add_header Access-Control-Allow-Origin *;
        add_header Access-Control-Allow-Methods 'GET, POST, OPTIONS';
        add_header Access-Control-Allow-Headers 'Content-Type';
    }

    # 你的其他网站配置保持不变
    location / {
        # 原有的网站配置
        # ...
    }
}
```

```bash
# 启用配置
sudo ln -s /etc/nginx/sites-available/artcure-ai /etc/nginx/sites-enabled/

# 测试配置
sudo nginx -t

# 重启 Nginx
sudo systemctl restart nginx
```

### 步骤 11: 配置防火墙和安全组

```bash
# Ubuntu UFW 防火墙
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw reload
```

**阿里云安全组设置：**
1. 登录阿里云控制台
2. 进入 ECS 实例管理
3. 点击"安全组配置"
4. 添加规则：
   - 协议类型：TCP
   - 端口范围：80/80
   - 源地址：0.0.0.0/0

### 步骤 12: 更新小程序云函数配置

在微信开发者工具中：

1. 编辑 `cloudfunctions/askAI/index.js`：
```javascript
// 更新 AI 服务器地址
const AI_SERVER_URL = 'http://your-server-ip/ai'
// 或使用域名
const AI_SERVER_URL = 'http://your-domain.com/ai'
```

2. 右键点击 `askAI` 文件夹 → "上传并部署：云端安装依赖"

### 步骤 13: 验证部署

```bash

    "user_id": "test_user",
```

## 🔄 后期迁移到新服务器

### 迁移准备

1. **数据备份**
```bash
# 在旧服务器上打包项目
cd /home/artcure/projects
tar -czf artcure-backup-$(date +%Y%m%d).tar.gz ArtCure/

# 下载备份文件
scp artcure@old-server-ip:/home/artcure/projects/artcure-backup-*.tar.gz ./
```

2. **记录配置**
```bash
# 导出环境变量
cat /home/artcure/projects/ArtCure/ai-server/.env > env-backup.txt

# 备份 Nginx 配置
sudo cp /etc/nginx/sites-available/artcure-ai ./nginx-backup.conf
```

### 新服务器部署

1. **重复部署步骤 1-8**
2. **恢复数据**
```bash
# 上传备份文件到新服务器
scp artcure-backup-*.tar.gz artcure@new-server-ip:/home/artcure/projects/

# 解压
cd /home/artcure/projects
tar -xzf artcure-backup-*.tar.gz
```

3. **重新配置服务（步骤 9-11）**

### 切换流量

1. **更新 DNS**（如果使用域名）
   - 修改 A 记录指向新服务器 IP

2. **更新云函数**
```javascript
const AI_SERVER_URL = 'http://new-server-ip/ai'
```

3. **验证新服务器**
```bash
curl http://new-server-ip/ai/health
```

4. **停止旧服务器**
```bash
sudo supervisorctl stop artcure-ai
```

## 🚨 故障排除

### 常见问题

1. **模型下载失败**
```bash
# 使用国内镜像
export HF_ENDPOINT=https://hf-mirror.com
pip install -r requirements.txt
```

2. **端口被占用**
```bash
# 查看端口占用
sudo netstat -tulpn | grep :8000
sudo kill -9 PID
```

3. **权限问题**
```bash
# 修复文件权限
sudo chown -R artcure:artcure /home/artcure/projects
chmod +x /home/artcure/projects/ArtCure/ai-server/venv/bin/python
```
