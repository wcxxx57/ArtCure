# ArtCure AI对话系统 - 架构与功能总结

## 🏗️ 系统架构

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   微信小程序    │    │   AI 服务器     │    │   DeepSeek API  │
│                 │    │                 │    │                 │
│  AI Chat Page   │────│  FastAPI +      │────│   LLM 生成      │
│  三种对话模式   │    │  RAG 检索       │    │   专业回复      │
│  UI 交互        │    │  上下文记忆     │    │                 │
└─────────────────┘    └─────────────────┘    └─────────────────┘
                                │
                        ┌─────────────────┐
                        │  FAISS 向量库   │
                        │                 │
                        │  艺术疗愈知识库 │
                        │  BGE中文嵌入    │
                        └─────────────────┘
```

## 📱 前端功能（miniprogram/pages/ai-chat/）

### 核心功能
- ✅ **三种对话模式**：树洞/疗愈师/日常陪伴
- ✅ **实时对话**：直接调用本地AI服务器
- ✅ **Markdown渲染**：支持标题、加粗、列表等格式
- ✅ **优化UI**：完整气泡显示、柔和色彩
- ✅ **快捷问题**：每种模式预设不同问题

### 已移除的冗余功能
- ❌ 云函数调用（`callCloudFunction`）- 简化为直接调用
- ❌ 本地回复模板的复杂逻辑 - 主要依赖AI服务器

### 文件结构
```
ai-chat/
├── index.js      # 对话逻辑，直接调用AI服务器
├── index.wxml    # UI模板，支持rich-text组件
├── index.wxss    # 优化的样式，完整气泡显示
└── index.json    # 页面配置
```

## 🤖 后端功能（ai-server/）

### 核心功能
- ✅ **上下文记忆**：每用户每模式独立会话历史
- ✅ **语义检索**：BGE中文嵌入 + FAISS向量检索
- ✅ **三种模式Prompt**：差异化的AI人格设置
- ✅ **智能检索优化**：基于对话历史优化查询
- ✅ **会话管理API**：查看/清除对话历史

### 检索机制详解
```python
# 1. 用户问题 + 对话历史 -> 优化查询
enhanced_query = get_contextual_retrieval_query(question, chat_history)

# 2. BGE模型向量化 -> 768维向量
embeddings = HuggingFaceEmbeddings(model_name="BAAI/bge-small-zh-v1.5")

# 3. FAISS相似度搜索 -> Top-3相关文档
docs = vector_store.similarity_search(enhanced_query, k=3)

# 4. 文档内容 + 对话历史 + 模式Prompt -> LLM生成
response = rag_chain.invoke(input_data)
```

### API端点
```
POST /chat          # 主要对话接口，支持上下文记忆
GET  /health        # 健康检查
POST /search        # 知识库搜索（调试）
GET  /session/{user}/{mode}    # 获取对话历史
DELETE /session/{user}/{mode}  # 清除对话历史
```

## 🎯 三种模式功能对比

| 模式 | 人格特点 | 知识重点 | 记忆功能 | 应用场景 |
|------|---------|---------|---------|---------|
| **树洞模式** | 温暖倾听、不评判 | 情感支持知识 | 关怀连续性 | 情绪倾诉、心理疏导 |
| **疗愈师模式** | 专业权威、循序渐进 | 艺术疗愈方法论 | 治疗进展跟踪 | 专业咨询、方案制定 |
| **日常陪伴** | 活泼友好、正能量 | 生活话题、趣事 | 友谊温暖延续 | 日常聊天、情感陪伴 |

## 🧠 上下文记忆机制

### 会话存储
```python
user_sessions = {
    "user123_comfort": [
        ChatMessage(role="user", content="今天心情不好"),
        ChatMessage(role="assistant", content="抱抱你..."),
        # 最多保存20条对话
    ],
    "user123_therapist": [...],
    "user123_companion": [...]
}
```

### 检索优化
- **代词理解**：「继续」、「那个方法」等结合历史上下文
- **主题延续**：基于近4轮对话关键词增强检索
- **个性化**：每个用户独立的对话记忆

## 🔍 检索技术栈

### 语义检索 vs 关键词检索
| 类型 | 优势 | 示例 |
|------|------|------|
| **语义检索** ✅ | 理解含义、同义词匹配 | 「心情糟糕」→「情绪低落处理」 |
| 关键词检索 | 精确匹配、速度快 | 「失眠」→「失眠」 |

### 当前实现
```
用户问题："睡不着觉"
   ↓
BGE嵌入模型向量化
   ↓  
FAISS相似度搜索
   ↓
匹配到："失眠的艺术疗愈方法"
   ↓
提供专业建议
```

## 📊 性能优化

### 前端优化
- **直接调用**：跳过云函数，减少延迟
- **本地渲染**：Markdown解析在客户端完成
- **状态管理**：模式切换不影响其他模式记忆

### 后端优化
- **向量缓存**：FAISS索引常驻内存
- **会话限制**：每模式最多20轮，避免过长上下文
- **检索优化**：智能查询重写，提升匹配准确度
