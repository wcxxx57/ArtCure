# 店铺数据库使用指南

## 概述

本指南说明如何在微信云开发中创建并初始化店铺数据库，以及如何使用搜索功能。

## 步骤一：创建云数据库集合

1. 打开微信开发者工具
2. 进入 **云开发控制台**
3. 选择 **数据库** 标签
4. 点击 **+** 号创建新集合
5. 集合名称输入：`shops`
6. 点击确定创建

## 步骤二：上传云函数

1. 在开发者工具中，右键点击 `cloudfunctions/shops` 文件夹
2. 选择 **上传并部署：云端安装依赖**
3. 等待部署完成

## 步骤三：初始化店铺数据

### 方法一：通过页面自动初始化（推荐）

1. 运行小程序，进入"疗愈馆"页面
2. 如果数据为空，系统会弹出对话框询问是否初始化
3. 点击"初始化"按钮
4. 等待数据导入完成

### 方法二：手动调用初始化函数

在小程序任意页面的 `onLoad` 中临时添加以下代码：

```javascript
const { initShopsData } = require('../../utils/shopsData.js')
initShopsData()
```

运行后删除此代码。

### 方法三：通过云开发控制台导入

1. 将 `miniprogram/utils/shopsData.js` 中的 `shopsData` 数组导出为 JSON 文件
2. 在云开发控制台的数据库中选择 `shops` 集合
3. 点击 **导入** 按钮
4. 选择 JSON 文件导入

## 数据结构

每条店铺记录包含以下字段：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| name | String | 店铺名称 |
| phone | String | 联系电话 |
| content | String | 服务内容描述 |
| address | String | 店铺地址 |
| rating | String | 评分显示文本 |
| ratingNum | Number | 评分数值（用于排序）|
| tags | Array | 服务标签数组 |

## 云函数 API

### 获取店铺列表

```javascript
wx.cloud.callFunction({
  name: 'shops',
  data: {
    action: 'list',
    data: {
      page: 1,
      pageSize: 20,
      category: 'all' // 可选：音疗、冥想、颂钵 等
    }
  }
})
```

### 搜索店铺

```javascript
wx.cloud.callFunction({
  name: 'shops',
  data: {
    action: 'search',
    data: {
      keyword: '颂钵',
      page: 1,
      pageSize: 20
    }
  }
})
```

### 获取店铺详情

```javascript
wx.cloud.callFunction({
  name: 'shops',
  data: {
    action: 'getById',
    data: {
      id: 'shop_id_here'
    }
  }
})
```

### 按分类获取

```javascript
wx.cloud.callFunction({
  name: 'shops',
  data: {
    action: 'getByCategory',
    data: {
      category: '冥想',
      page: 1,
      pageSize: 20
    }
  }
})
```

### 获取所有标签

```javascript
wx.cloud.callFunction({
  name: 'shops',
  data: {
    action: 'getTags'
  }
})
```

## 注意事项

1. 确保已开通云开发环境
2. 确保云函数已正确部署
3. 数据初始化只需执行一次
4. 如需更新数据，可先调用 `clear` 清空，再重新初始化

## 问题排查

### 数据加载失败

1. 检查云函数是否部署成功
2. 检查集合名称是否正确（`shops`）
3. 检查网络连接

### 搜索无结果

1. 确认数据已初始化
2. 尝试使用更简短的关键词
3. 检查关键词是否有错别字

## 验证与检查：如何确认云数据库与云函数已实现

1. 在微信开发者工具中打开“云开发”面板，确认**环境 ID** 已设置且云托管已启用。
2. 在“数据库”标签搜索集合 `shops`：
   - 如果存在：点击进入查看数据条目（应包含 `name`, `content`, `tags` 等字段）
   - 如果不存在：请参照上文步骤创建集合并初始化数据
3. 在“云函数”标签确认 `shops` 云函数已上传并部署：
   - 点击 `shops` 云函数，查看最近部署记录，确保没有报错
   - 在“函数测试”中使用模拟事件测试以下基本操作：

测试示例（函数测试输入 JSON）：

- 列表查询（list）
```json
{ "action": "list", "data": { "page": 1, "pageSize": 5 } }
```

- 搜索（search）

4. 使用控制台日志确认云函数返回结果无错误，注意查看 `success` 字段

## 搜索接口增强说明（新增参数与行为）

云函数 `shops` 的 `search` 操作已增强，支持以下参数：

| 参数 | 类型 | 说明 | 可选值/示例 |
|------|------|------|-------------|
| keyword | String | 必填，搜索关键词 | "颂钵", "冥想" |
| page | Number | 页码 | 1 |
| pageSize | Number | 每页数量 | 20 |
| searchType | String | 搜索类型：控制搜索策略 | `shop` / `resource` / `auto`（默认） |
| region | String | 可选，地区筛选 | "上海" / "静安区" |
| category | String | 可选，标签分类筛选 | "冥想" / "音疗" / `all`（默认） |

搜索策略说明：
- shop：仅按店名匹配，适合用户想找具体店铺名称时使用
- resource：基于店铺描述、标签、地址进行匹配，适合查找服务或资源
- auto：宽松模式，综合店名与资源匹配（兼顾两者）

返回结果中新增字段：`searchType`, `region`，并按数值评分 `ratingNum` 倒序排序。

## 前端示例：如何调用并展示搜索结果

### 搜店铺（按名字）
```javascript
wx.cloud.callFunction({
  name: 'shops',
  data: {
    action: 'search',
    data: {
      keyword: '安和颂钵',
      searchType: 'shop',
      page: 1,
      pageSize: 10
    }
  }
}).then(res => {
  // res.result.data 为店铺数组
}).catch(console.error)
```

### 搜资源（按服务/描述/标签/地区）
```javascript
wx.cloud.callFunction({
  name: 'shops',
  data: {
    action: 'search',
    data: {
      keyword: '冥想',
      searchType: 'resource',
      region: '静安区',
      category: '冥想',
      page: 1,
      pageSize: 20
    }
  }
})
```

- 调用 `search`，获取 `data` 后在小程序端对 `name` 与 `content` 中匹配到的关键词做高亮显示

## 搜索性能与语义改进建议

当前实现为基于正则的模糊匹配，能满足大部分关键词搜索。若需更高级的语义搜索建议两步升级：

1. 轻量级语义增强（无需外部服务）
   - 在导入数据时，为每条店铺生成简短的`search_text`字段（合并 name + content + tags + address），并做关键词分词缓存（可使用 jieba 分词导出关键词数组）
   - 在搜索时，对用户输入进行简单分词，匹配 `search_text` 中命中的关键词数量并按相关度排序

2. 语义向量检索（推荐；最佳体验）
   - 使用开放模型或本地 embedding 服务（例如 BGE 或其他中文 embedding）对 `search_text` 生成向量并存入向量索引（如 FAISS）
   - 在云函数或后端增加一个向量检索接口：先用用户 query 检索向量索引得到 top-k 店铺 id，再从数据库中拉取详情返回

## 开发者注意事项

- region 与 category 参数在搜索中为可选项，但建议在 UI 中提供便捷的下拉筛选
- 对 `ratingNum` 字段可能存在 0 值或字符串状态，要保证前端排序/展示兼容
- 数据量较大时，建议采用向量检索或后端分页缓存方案以提高性能
