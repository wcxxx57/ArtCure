## 二、数据来源与获取方式

### 2.1 大众点评（实体店）

**数据特点**：结构化程度高，信息完整

**获取方式**：
1. ✅ **人工录入**（推荐）：在店铺名字.xlsx中整理后导入
2. ⚠️ **API获取**：需申请官方开放平台权限
3. ❌ **爬虫**：存在法律风险，不推荐

**数据处理**：直接映射，无需LLM清洗

```python
# 示例：从Excel导入大众点评数据
from data_collection.dianping_collector import DianpingCollector

collector = DianpingCollector()
data = collector.import_from_excel("店铺名字.xlsx")
```

### 2.2 小红书（个人IP/活动）

**数据特点**：非结构化，需要LLM提取

**获取方式**：
1. ✅ **人工复制粘贴**：复制笔记内容到JSON
2. ⚠️ **第三方数据服务**：需付费
3. ❌ **爬虫**：存在法律风险

**数据处理**：需要LLM清洗提取

```python
# 示例：使用LLM清洗小红书数据
from data_collection.llm_cleaner import LLMDataCleaner

cleaner = LLMDataCleaner()
result = cleaner.extract_resource_info(
    title="上海静安｜超治愈的曼陀罗绘画体验！",
    content="周末去体验了一家...",
    source="xhs"
)
```

**LLM清洗 Prompt**：
```
请从这段文本中提取以下信息：
- 活动时间
- 详细地址
- 费用（数字）
- 治疗师姓名
- 疗愈形式（从绘画/舞动/音乐等选择）
- 目标人群
- 情绪标签
如果未提及，返回null。
```

### 2.3 微信公众号（专业机构）

**数据特点**：专业详细，适合深度疗愈资源

**获取方式**：人工整理添加

### 2.4 合作资源

**数据特点**：独家资源，人工添加

### 2.5 高德地图（POI数据）

**数据特点**：覆盖广、更新快，适合补充基础信息

**获取方式**：
1. ✅ **高德地图API**：申请开发者Key
2. ❌ **爬虫**：存在法律风险，不推荐

**数据处理**：部分字段直接映射，部分需人工补充

```python
# 示例：使用高德地图API采集数据
import requests
import os

AMAP_API_KEY = os.getenv("AMAP_API_KEY")

response = requests.get(
    "https://restapi.amap.com/v3/place/text",
    params={
        "key": AMAP_API_KEY,
        "keywords": "疗愈馆",
        "city": "上海",
        "children": 1
    }
)

data = response.json()
```

# 疗愈馆数据采集指南

## 📋 概述

本指南介绍如何使用 **JustOneAPI** 平台采集大众点评、小红书等平台的疗愈馆数据。

### 为什么选择 JustOneAPI？

| 优势 | 说明 |
|------|------|
| ✅ 多平台聚合 | 一个 Token 访问多个平台（小红书、大众点评、美团等） |
| ✅ 合规数据 | 官方数据服务，避免爬虫风险 |
| ✅ 简单接入 | 标准 HTTP 接口，开箱即用 |
| ✅ 去重机制 | 内置跨平台数据去重 |

---

## 🚀 快速开始（5分钟）

### 步骤 1：获取 JustOneAPI Token

1. 访问 [JustOneAPI 注册页面](https://user.justoneapi.com/zh/sign-up)
2. 注册账号并登录
3. 在个人中心获取你的 **Token**

### 步骤 2：配置环境

```powershell
# 进入数据采集目录
cd E:\ArtCure\data_collection

# 复制配置文件
copy .env.example .env
```

**编辑 `.env` 文件，填入你的 Token：**

```ini
# ========== 在这里填入你的 Token ==========
JUSTONEAPI_TOKEN=your_token_here
# ==========================================

# API 环境（中国大陆用 prod-cn）
JUSTONEAPI_ENV=prod-cn
```

### 步骤 3：安装依赖

```powershell
pip install requests python-dotenv
```

### 步骤 4：运行采集

```powershell
# 采集上海的疗愈馆数据（默认从小红书）
python justoneapi_collector.py --city 上海

# 指定平台
python justoneapi_collector.py --city 上海 --platforms xhs dianping

# 自定义关键词
python justoneapi_collector.py --city 北京 --keywords 冥想 颂钵 艺术疗愈
```

## 🎯 数据去重机制

采集器内置跨平台去重：

```
店铺唯一标识 = MD5(店铺名 + 城市 + 区域)
```

同一家店铺在小红书和大众点评上只会保留一条记录。

## 📥 导入云数据库

```javascript
  await db.collection('healing_resources').add({ data: item });
}
```

## ⚠️ 注意事项

1. **Token 安全**：不要将 `.env` 文件提交到 Git
2. **调用计费**：JustOneAPI 按成功调用计费，注意余额
3. **速率限制**：程序已内置限速，避免触发 302 错误
4. **数据清洗**：小红书数据是非结构化的，部分字段通过正则提取，可能不完整

## 🔧 常见问题

### Q: 出现 "Token 无效" 错误 (code=100)
A: 检查 `.env` 文件中的 `JUSTONEAPI_TOKEN` 是否正确

### Q: 出现 "余额不足" 错误 (code=601)
A: 需要在 JustOneAPI 平台充值

### Q: 出现 "超出速率限制" (code=302)
A: 等待几秒后重试，程序会自动处理

### Q: 采集到的地址/电话为空
A: 小红书笔记中不一定包含这些信息，需要后续人工补充
