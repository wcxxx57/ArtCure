## 四、文档编写规范

### 4.1 格式规范

```markdown
# 文档标题

## 一、大类标题

### 1. 小节标题

#### 具体内容

【场景】具体描述

【用户可能说】
- "..."
- "..."

【AI 推荐回应】
初级共情："..."
深度共情："..."
引导建议："..."

【禁忌回应】
- ❌ "你不应该这样想"
- ❌ "别想太多了"

【推荐活动】
- 活动名称：适用原因
```

### 4.2 内容原则

| 原则 | 说明 | 示例 |
|------|------|------|
| **共情优先** | 先理解感受，再给建议 | ✅ "听起来你很累了" → ❌ "你应该早点睡" |
| **不评判** | 避免价值判断和道德说教 | ✅ "这让你很难受" → ❌ "你不应该这样想" |
| **开放提问** | 使用开放式问题 | ✅ "你愿意说说吗？" → ❌ "是不是因为...？" |
| **具体化** | 提供可操作的建议 | ✅ "试着深呼吸3次" → ❌ "放松一下" |
| **尊重自主** | 尊重用户的选择 | ✅ "如果你愿意的话..." → ❌ "你必须..." |
| **温和边界** | 委婉表达能力边界 | ✅ "这种情况，专业咨询师能帮到你更多" |

### 4.3 语言风格

- **温暖但不过度亲昵**：像一个温柔的朋友，不是甜腻的恋人
- **专业但不生硬**：融入心理学知识，但用通俗语言表达
- **积极但不否定情绪**：给予希望，但先接纳当下的感受
- **简洁但不冷漠**：语言精炼，但保持情感温度

```
5. 边界测试："我不想活了"（危机识别）
```

## 八、知识图谱集成方案

### 8.1 为什么需要知识图谱？

| 方案 | 优势 | 局限 |
|------|------|------|
| **纯 RAG** | 实现简单，语义检索 | 缺乏结构化关系，难以推理 |
| **纯知识图谱** | 关系清晰，支持推理 | 难以处理自然语言 |
| **GraphRAG** | 结合两者优势，既能语义检索又能关系推理 | 实现复杂度较高 |

**适合 ArtCure 的场景**：
- 用户说"我失眠"→ 图谱能关联：失眠 → 可能原因（焦虑/压力）→ 推荐疗法 → 具体活动
- 用户说"我和妈妈吵架了"→ 图谱能关联：亲子冲突 → 情绪类型 → 对应话术 → 推荐活动

### 8.2 知识图谱结构设计

```
┌─────────────────────────────────────────────────────────────┐
│                    ArtCure 知识图谱                          │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│   ┌──────────┐     触发     ┌──────────┐     适用     ┌──────────┐
│   │  情绪    │─────────────▶│  场景    │─────────────▶│  疗法    │
│   │  节点    │              │  节点    │              │  节点    │
│   └──────────┘              └──────────┘              └──────────┘
│       │                         │                         │
│       │ 表现为                  │ 包含                    │ 包含
│       ▼                         ▼                         ▼
│   ┌──────────┐              ┌──────────┐              ┌──────────┐
│   │  症状    │              │  话术    │              │  活动    │
│   │  节点    │              │  节点    │              │  节点    │
│   └──────────┘              └──────────┘              └──────────┘
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 8.3 节点与关系定义

#### 节点类型

| 节点类型 | 属性 | 示例 |
|----------|------|------|
| **情绪 (Emotion)** | name, intensity_levels, description | 焦虑、抑郁、愤怒 |
| **场景 (Scenario)** | name, triggers, user_expressions | 考试焦虑、失眠、分手 |
| **症状 (Symptom)** | name, physical, psychological | 心跳加速、失眠、注意力不集中 |
| **疗法 (Therapy)** | name, type, theory_base | 绘画疗愈、正念冥想 |
| **活动 (Activity)** | name, duration, materials, steps | 曼陀罗绘画、4-7-8呼吸 |
| **话术 (Script)** | type, content, tone | 共情话术、引导话术 |
| **危机 (Crisis)** | level, keywords, response | 高风险、中风险 |
| **资源 (Resource)** | type, contact, description | 心理热线、咨询平台 |

#### 关系类型

| 关系 | 描述 | 示例 |
|------|------|------|
| `TRIGGERS` | 场景触发情绪 | (考试焦虑)-[TRIGGERS]->(焦虑) |
| `MANIFESTS_AS` | 情绪表现为症状 | (焦虑)-[MANIFESTS_AS]->(失眠) |
| `SUITABLE_FOR` | 疗法适用于情绪 | (绘画疗愈)-[SUITABLE_FOR]->(焦虑) |
| `CONTAINS` | 疗法包含活动 | (绘画疗愈)-[CONTAINS]->(曼陀罗绘画) |
| `RESPONDS_WITH` | 场景对应话术 | (失眠场景)-[RESPONDS_WITH]->(共情话术) |
| `ESCALATES_TO` | 症状升级为危机 | (持续失眠)-[ESCALATES_TO]->(中风险) |
| `REFERS_TO` | 危机转介资源 | (高风险)-[REFERS_TO]->(心理热线) |
| `RELATED_TO` | 情绪相互关联 | (焦虑)-[RELATED_TO]->(抑郁) |

#### 方案 B：使用 NetworkX + JSON（轻量级方案）

```python
# 适合小规模项目，无需额外数据库
# pip install networkx

import networkx as nx
import json

class ArtCureKnowledgeGraph:
    def __init__(self):
        self.graph = nx.DiGraph()
    
    def add_emotion(self, name, **attrs):
        self.graph.add_node(name, type='emotion', **attrs)
    
    def add_scenario(self, name, triggers_emotion, **attrs):
        self.graph.add_node(name, type='scenario', **attrs)
        self.graph.add_edge(name, triggers_emotion, relation='TRIGGERS')
    
    def add_activity(self, name, suitable_for_emotions, **attrs):
        self.graph.add_node(name, type='activity', **attrs)
        for emotion in suitable_for_emotions:
            self.graph.add_edge(name, emotion, relation='SUITABLE_FOR')
    
    def get_activities_for_emotion(self, emotion):
        """根据情绪查找推荐活动"""
        activities = []
        for node, data in self.graph.nodes(data=True):
            if data.get('type') == 'activity':
                if self.graph.has_edge(node, emotion):
                    activities.append(node)
        return activities
    
    def save(self, path):
        data = nx.node_link_data(self.graph)
        with open(path, 'w', encoding='utf-8') as f:
            json.dump(data, f, ensure_ascii=False, indent=2)
    
    def load(self, path):
        with open(path, 'r', encoding='utf-8') as f:
            data = json.load(f)
        self.graph = nx.node_link_graph(data)

# 使用示例
kg = ArtCureKnowledgeGraph()
kg.add_emotion('焦虑', description='对未来的担忧')
kg.add_scenario('考试焦虑', triggers_emotion='焦虑',

kg.add_activity('曼陀罗绘画', suitable_for_emotions=['焦虑', '压力'],
                duration='15-30分钟')
kg.save('knowledge_graph.json')
```

### 8.5 GraphRAG 集成方案

将知识图谱与现有 RAG 结合：

```python
# ai-server/graph_rag.py

from langchain.chains import GraphCypherQAChain
from langchain_community.graphs import Neo4jGraph
from langchain_openai import ChatOpenAI

class GraphRAGSystem:
    def __init__(self):
        # 向量检索（现有 RAG）
        self.vector_store = load_faiss_index()
        
        # 知识图谱
        self.graph = Neo4jGraph(url="bolt://localhost:7687")
        
        # LLM
        self.llm = ChatOpenAI(model="deepseek-chat")
    
    def query(self, user_input, mode="comfort"):
        # 1. 向量检索：获取相关文档
        docs = self.vector_store.similarity_search(user_input, k=3)
        context = "\n".join([doc.page_content for doc in docs])
        
        # 2. 图谱查询：获取结构化关系
        graph_context = self.query_graph(user_input)
        
        # 3. 合并上下文
        full_context = f"""
        【相关知识】
        {context}
        
        【结构化信息】
        {graph_context}
        """
        
        # 4. 生成回复
        return self.generate_response(full_context, user_input, mode)
    
    def query_graph(self, user_input):
        """从知识图谱查询相关信息"""
        # 识别用户情绪关键词
        emotion = self.extract_emotion(user_input)
        
        if emotion:
            # 查询相关活动和话术
            result = self.graph.query(f"""
            MATCH (e:Emotion {{name: '{emotion}'}})
            OPTIONAL MATCH (a:Activity)-[:SUITABLE_FOR]->(e)
            OPTIONAL MATCH (s:Scenario)-[:TRIGGERS]->(e)
            OPTIONAL MATCH (s)-[:RESPONDS_WITH]->(script:Script)
            RETURN e.name as emotion, 
                   collect(DISTINCT a.name) as activities,
                   collect(DISTINCT script.content) as scripts
            """)
            return result
        return ""
```
